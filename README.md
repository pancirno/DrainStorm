\# David Horner's Drain Storm



A classic Windows 3.11 game, recompiled using vibeslopping techniques using variety of GPT models in order to make it run on modern systems.



The decomp went through several passes, with first pass resulting with completely non-functional mess, with second pass resulting with somewhat playable game but with so many differencies between the original game it warranted a third pass, with the model asked with going through every single decompiled function to find the differencies between the old code and new one. Admittely only the second pass was thoroughly tested by myself, but I believe the test produced during the second pass should cover about everything.



If the time allows it, I'm probably going to manually refactor the code for more maintainability and modding possibilities. Linux/Macos support would be a natural next step but the game leans a lot into WinApi.
